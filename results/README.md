# Verified model results

This directory contains the paper-ready outputs generated from 20 completed runs on the fixed 282-image test set. `PAPER_READY.json` records the experiment version, manifest identity, model set, seed set, and completion count.

Key files include the overall and class-wise tables, MPS training-efficiency table, run-level metrics, seed rankings, exact McNemar tests with Holm adjustment, and the 600 dpi Figure 16 generated from the same saved predictions.

Model checkpoints and source images are intentionally excluded because of size and source-data licensing considerations.
